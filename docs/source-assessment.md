# Avaliação das fontes

## Regra de validação

Cada conector deve usar uma fonte oficial do supermercado. Antes de ativá-lo, registrar:

- URL oficial utilizada;
- necessidade de selecionar loja ou postcode;
- existência de API, JSON-LD ou dados públicos estruturados;
- dependência de JavaScript;
- promoções condicionadas a cartão/aplicativo;
- limitações de disponibilidade regional;
- data do último teste real.

## Situação inicial

| Supermercado | Estado | Observação |
|---|---|---|
| Lidl | Pendente | Validar catálogo e promoções oficiais sem contornar bloqueios. |
| Aldi | Pendente | Validar catálogo e folder semanal oficial. |
| Jumbo | Pendente | Validar busca pública e dependência de loja/postcode. |
| Albert Heijn | Pendente | Validar busca, Bonuskaart e localização. |
| Hoogvliet | Pendente | Validar busca e promoções regionais. |
| Makro | Pendente | Verificar login empresarial, preços com/sem BTW e quantidades mínimas. |

Nenhum conector deve ser marcado como funcional sem execução real e confirmação do preço na fonte oficial.
